# YouBoard - 剪贴板历史管理工具

一款轻量级 Windows 剪贴板管理工具，自动记录复制历史，支持文本、图片、文件、网址四大分类，附带桌面实时小组件与手机传输，随取随用。

## 🆕 v3.2.6 更新内容

- **发版前自动跑回归测试（新增门禁）** — 回归测试脚本搬进仓库（`tools/verify_all.py`），CI 在打包**之前**先跑一遍，不通过就不打包、不发版；换机器 / 在 CI 上都不用改路径，失败会以非 0 退出码中断流程
- **版本号只有一个来源** — 新增 `youboard_version.py`（唯一来源）与 `tools/sync_version.py`（生成 `version_info.txt`、`version_defines.iss`，并可一并更新文档里的下载文件名）。程序本体、macOS 的 CFBundleVersion、CI 产物名都直接读它，安装包用 `#include "version_defines.iss"`——以后发版只改一个文件
- **README 顶部加了徽章** — 最新版本 / 下载量 / 支持平台 / License / Star，由 shields.io 动态生成，发新版后版本号徽章会自动更新

- **修掉"从上往下扫过按钮时手型光标不出现"** — 设置窗口里鼠标从上往下经过按钮，光标不变手型，只有从下往上才有。根因是那个"光标兜底刷新"依赖 `QApplication.widgetAt`，而它在自己的无边框 / 半透明窗口上经常取不到控件（返回 None），整条兜底就失效了；现在改成沿窗口自己的控件树用 `childAt` 查找（重叠时优先对话框、再取最具体的那个窗口）
- **可点控件的光标统一** — 之前开关、以及少数按钮（设置里的「选择背景图片」「恢复默认」、手机传输里的「复制链接 / 刷新二维码 / 关闭」等）没设手型光标，现在统一补齐（只在控件可用、可见时生效）
- **「自定义皮肤」与「历史保留策略」统一风格** — 两个弹层现在共用同一套卡片样式（同一基类）：同样的圆角卡片、圆形图标、标题 / 副标题层级、右下「取消 + 保存」；调风格只改一处
- **置顶的记录一眼能认出来** — 列表里被置顶的行，内容前会有一个主题色「置顶」小胶囊（任何分类里都有）
- **「历史保留策略」的自定义行重做** — 原来的「小时 / 天」下拉框有直角外框、而且靠近底部时会往上翻盖住别的控件；现在换成两个小胶囊按钮，和上面那排选项同一套样式

> 从 v3.2.3 及更早版本升级，以下内容也一并包含。

- **光标不再被锁在缩放箭头上** — 以前贴着窗口 / 小组件的边缘缩放一次之后，光标会一直卡成缩放箭头（"缩放 → 打开设置 → 关掉设置"之后必现）：模态窗口开着时主窗口收不到鼠标事件，记在窗口上的缩放光标再也没机会被改回来，鼠标停在表格这类子控件上也不会更新。现在子控件也上报鼠标移动、松手时按真实位置重算、鼠标进入窗口时重算、**关掉设置后立刻重算**；实测直接读 Windows 系统光标：贴边=缩放箭头，中间 / 表格上=普通箭头
- **更新时不再闪终端** — 更新脚本原来用 `timeout.exe` 做等待，在这种无控制台环境里它起不来也不等待，重试会瞬间连发；现在改用 `ping` 真正等待、重试上限 60 次，并用隐藏控制台方式启动，实测整个更新过程 0 个可见控制台窗口
- **文件标签按类型细分** — 「文件」标签里新增一排筛选按钮（全部 / 视频 / 图片 / 设计源文件 / 音频 / 文档 / 压缩包 / 程序 / 代码 / 字体 / 其他，带数量），每行文件名前显示所属细分，共覆盖 403 个扩展名（mp4→视频、psd/ai→设计源文件、wav/mp3→音频、rar/7z→压缩包…）。「全部」标签里这些记录依旧是"文件"，不受影响

- **更新过程不再弹 `timeout.exe - Application Error`** — 更新脚本原来用 `timeout.exe` 做等待，在没有控制台句柄 / 句柄异常的环境里它起不来，会弹 `0xc0000142` 的错误框而且不等待；现在等待改用 `ping`，不依赖控制台
- **替换 EXE 的重试有了上限** — 旧文件万一被占用，以前会一直循环；现在最多重试 60 次后照常继续，不会卡死
- **修掉"更新完要先关掉再打开"的报错** — 应用内更新（3.2.0 → 3.2.1）完成后会弹 `Security validation failure: unexpected name of application's home directory!`，必须退出重开才能用。原因是新版 PyInstaller（6.22.3）给 onefile 程序加了安全校验，而更新时启动新版本的批处理**继承了旧进程的临时目录环境变量**，新版本校验不过就直接退出了；现在更新器会把这类变量清干净再启动新版本，更新完自动打开、不再报错
- **打包工具版本固定** — 构建脚本把 PyInstaller 固定到 `6.22.3`，避免以后又因为自动升级到最新版而引入新的启动校验/行为
- **设置界面的"分组感"重做** — 以前每个功能模块的标题是 11px 的次级灰，比模块里的条目还小、还淡（读起来像注脚），现在提升为 13px 主文字色标题；模块内的条目文字由粗体降为中等，把视觉重心让给标题；主题色竖条和圆角底片保留
- **用留白表达分组** — 以前"模块之间 7px、模块内部最多 11px"，组间反而比组内更紧，所以一眼看去分不清哪些是分组、哪些是分组里的内容；现在组间 15px > 组内 7px，"分组标题 / 分组内容 / 说明文字"三级一眼分得清

> 从 v3.0.0 及更早版本升级，以下内容全部包含在内。

- **复制 / 预览不再"缺斤少两"** — 鼠标点在「内容预览」那一格按 `Ctrl+C` 时，以前复制走的是那格的**显示文字**（换行被写成 `⏎`、超过 120 字还会被截断成 `…`），粘出来自然就不完整、还带一堆回车符号；现在列表里 `Ctrl+C` 复制的始终是**完整原文**，并且这类"预览文字"不会再被当成新内容记成一条重复记录
- **预览面板完整显示全文** — 预览区以前最多显示 2 万字，长文会被截断；现在正常长度的文本都完整显示（只有超大文本才提示截断）
- **列表显示修复** — 「文件」列表的 数量 / 格式 / 大小、「图片」列表的 格式 / 尺寸 / 大小 之前会被截断（`2109.5 MB`、`AI, PSD`、`2560x1440` 显示成 `…`），现在按内容自适应宽度；这几列的文字也改成居中，和表头对齐
- **大小单位支持到 GB / TB** — 超过 1024 MB 自动进位（`2109.5 MB` → `2.1 GB`，再往上 `3.0 TB`），不再出现两千多 MB 这种读法
- **「全部」分类更完整** — 文件 / 图片条目在「全部」里会连同 格式、大小（图片还有尺寸）一起显示，不再只有文件名
- **复制文件不再"多出一条文件名文本"** — 复制文件时剪贴板里附带的文件名文本不会再被当成普通文本收录（三重判断：文件列表 / 文件类格式 / 文件名形态），普通文本复制不受影响
- **缩放窗口更顺滑** — 拖拽缩放时不再逐帧重绘预览大图（明显卡顿的根因）；背景图改为"保持比例铺满、多出的裁掉"，既不露底也不会被拉伸变形
- **退出更干净** — 退出时先停掉还在播放的提示音，避免 PyInstaller 临时目录被占用而弹出 "Failed to remove temporary directory" 警告
- **界面语言更纯** — 英文界面里不再夹中文、中文界面里不再夹多余的英文对照（快捷键、`GitHub`/`WebDAV` 这类专有名词照常保留）
- **检查更新更稳** — GitHub API 被限流（同一出口 IP 每小时 60 次）或网络受限时，自动改用 Releases 页面获取最新版本号再下载，境外网络 / 共享 IP 也能正常更新
- **「全部」分类** — 一屏看全文本 / 图片 / 文件 / 网址，每条前面带圆角类型标签，跨分类关键词检索
- **接管 Win+V（可选）** — 开启后按 `Win+V` 直接打开 / 收起本工具（再按一次即收起），并可一键关闭系统剪贴板历史
- **复制 / 粘贴提示音** — 默认关闭；可分别开关、各自选音效（自带音效或自定义音频）。在其它程序里复制、粘贴都会响，而且**每次都响**
- **手机端增强** — 手机可直接上传图片 / 文件到电脑；新增「读取手机剪贴板并发送」；图片不再反复重载、来回跳
- **界面统一** — 提示 / 警告 / 确认弹窗全部换成与「检查更新」一致的卡片样式；左下角快捷键提示改为按你的实际设置显示；云同步窗口布局整理
- **更稳更快** — 超过 256KB 的大文本正文单独存盘、写盘防抖 + 后台线程，历史文件保持小巧；修复若干界面与稳定性问题

## 📱 手机传输

把电脑剪贴板"搬到"手机浏览器，无需安装任何手机 App，也不经过云端。

### 使用方法

1. 电脑端：托盘右键 →「发送到手机…」，或 设置 → 手机传输 → 打开传输窗口
2. 手机和电脑连接**同一个 Wi-Fi / 局域网**
3. 用手机相机 / 微信扫窗口里的二维码，或在手机浏览器手动输入链接
4. 手机页面自动展示全部剪贴板历史：
   - **文本 / 网址**：点一下即可复制到手机
   - **图片**：直接预览，长按保存
   - **文件**：一键下载
   - **上传**：点「上传图片 / 文件到电脑」，图片进「图片」分类，其它文件进「文件」分类（单文件上限 64MB）
5. 反向传输：在页面底部输入文字点「发送」，内容自动写入电脑系统剪贴板并进入历史记录

### 常见问题

- **手机打不开页面？** 先确认手机和电脑在同一 Wi-Fi；若窗口出现「IP 地址」下拉框，请选择 `192.168.x.x` 开头的那个（多个网卡 / VPN 时自动列出全部候选）
- **朋友 / 其他设备打不开？** 让对方设备连接同一个 Wi-Fi（不要用访客网络或手机热点），并关闭对方设备上的 VPN / 梯子（本地局域网不走代理）
- **还是连不上？** 首次监听时 Windows 防火墙会弹窗，请选择「允许访问」；应用也会自动尝试添加防火墙放行规则（覆盖专用 / 公用网络）
- **关掉窗口还能连吗？** 可以。关闭传输窗口后服务保持运行，托盘菜单的「停止手机传输（端口）」可随时关闭，退出应用也会自动停止
- **安全吗？** 每次启动随机生成 token（链接自带、刷新二维码即失效），服务只监听局域网、不暴露公网；停止传输或退出应用立即断开

## ☁️ 云同步

把剪贴板历史加密备份到云端，换设备也能恢复：

1. 设置 → 云同步 →「打开同步窗口」，选择后端（GitHub Gist / WebDAV）
2. 填入对应凭据（Gist 用带 `gist` 权限的 Token；WebDAV 填目录地址 + 账号密码，如坚果云需用应用密码）
3. 设置「同步密码」（至少 4 位）——历史数据会先用这个密码端到端加密，云端只保存密文
4. 点「上传到云端」备份；新设备上点「从云端下载」即可合并恢复

说明：同步为手动触发；下载按条目 hash 去重、保留时间较新的版本；图片文件本体暂不同步（第二期），换设备后图片条目保留但预览需待图片同步。

### YouBoard v3.2.3

- 🧯 **更新脚本不再依赖 `timeout.exe`**
  - 现象：更新时会弹出 `timeout.exe - Application Error`，提示"应用程序无法正常启动(0xc0000142)"
  - 原因：更新脚本原来用 `timeout /t N /nobreak` 做等待，而脚本是被以 DETACHED_PROCESS（没有控制台）方式拉起的；`timeout.exe` 在这种环境里起不来，于是弹错误框，而且**没有真的等待**，紧接着的"删除旧 EXE"重试就变成了空转
  - 修复：等待改用 `ping -n N 127.0.0.1 >nul`，不依赖控制台；重试次数也加了上限（60 次），不会再无限循环
